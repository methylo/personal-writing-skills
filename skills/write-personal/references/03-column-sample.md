# 03 완성 칼럼 견본 (3단계 초안과 6단계 검수의 품질 기준)

이 견본은 자리 배치를 보여 주는 축약 예시다. 기본 분량은 본문 공백 포함 900~1,000자이며, 사용자가 분량을 지정하면 그 요청을 우선한다. 아래 견본의 길이를 기본 출력 분량으로 삼지 않는다. 수업용 가상 예시이며, 문장·표현·소재를 필자의 글에 옮겨 쓰지 않는다. 필자의 글은 필자의 메모로만 쓴다.

## 견본 (공백 포함 약 640자)

```
제목: 결심보다 시작 장치를 바꾼다

[도입] 저녁에 책상에 앉아 읽을 글을 펼쳤다. 알림을 확인하다가 다른 화면까지 보았다. 글은 펼쳐 둔 채였고, 내가 보고 있는 것은 휴대폰이었다. 읽겠다는 마음은 처음부터 있었다. 자리에 앉은 것과 읽기 시작한 것은 달랐다. 그 사이를 메우는 것은 결심이 아니었다.

[근거] 휴대폰을 뒤집어 놓았다. 그리고 펼쳐 둔 글의 한 문단을 다시 읽었다. 집중이 완벽해진 것은 아니다. 그래도 멈춘 자리에서 다시 시작했다. 그날 바꾼 것은 마음가짐이 아니라 책상 위 물건 하나의 위치였다. 결심은 그대로였는데 행동이 달라진 이유는, 손이 먼저 가던 물건이 눈앞에서 사라졌기 때문이라고 생각한다. [확인 필요: 주의를 흩뜨리는 물건과 집중에 관한 자료 1개]

[판단 기준] 집중이 안 되는 날에는 두 가지를 물어본다. 책상 위에서 가장 먼저 손이 가는 것은 무엇인가. 그것 하나를 치우면 첫 문단을 읽을 수 있는가. 이 질문의 답은 사람마다 다르다. 내게는 휴대폰이었지만, 다른 사람에게는 열어 둔 메신저 창이나 켜 둔 영상일 수 있다. 답이 떠오르지 않으면 지난번에 읽기를 멈춘 순간을 떠올려 본다. 그때 손에 무엇이 있었는지가 답이다. 치울 수 없다면 보이지 않는 곳으로 옮겨도 된다. 중요한 것은 답을 찾은 뒤 바로 하나를 치우는 일이다.

[정리] 다시 결심하기보다, 시작 장치 하나를 바꿔 보자.
```

## 이 견본이 기준을 지킨 곳

| 자리 | 지킨 기준 |
| --- | --- |
| 제목 | 주장 한 줄이며, 근거 카드 범위를 넘지 않는다 |
| 도입 | 일반론이 아니라 필자가 본 장면으로 시작한다. 첫 문단 끝에서 주장('결심이 아니었다')이 드러난다 |
| 근거 | 메모의 행동('뒤집어 놓았다')을 그대로 쓰고, 한계('완벽해진 것은 아니다')를 남긴다. 해석은 '생각한다'로 필자의 판단임을 밝힌다 |
| 판단 기준 | 독자가 자기에게 대 볼 질문 2개를 준다 |
| 정리 | 제목을 그대로 반복하지 않고 같은 뜻의 다른 문장으로 끝낸다 |
| 남은 일 | [확인 필요] 1개는 제출 전에 자료로 채우거나 문장을 뺀다 |
