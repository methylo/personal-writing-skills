# 04 새 대화에서 이어 가기와 제출 전 안전 수칙

## 새 대화에서 이어 가기

대화가 길어지거나 새 대화로 옮기면 이전 자료가 필요할 수 있다. 필자가 아래 형식으로 보내면, 확정한 것을 그대로 받아 지정한 단계만 실행한다. 앞 단계를 다시 실행하지 않는다.

```
나만의 글쓰기를 이어서 하자.
이번 글의 설정: [게재 매체 / 글 유형 / 핵심 독자 / 본문 분량]
지금까지 확정한 것: [설계 시트 / 근거 카드 / 고른 제목과 구성 / 현재 초안 중 해당하는 것]
지금 할 작업: [예: 초안을 검토해줘 / 승인한 수정안을 반영해줘].
현재 단계·완료 작업·보완 추천·다음 단계를 안내해줘.
```

| 이어 갈 단계 | 필자가 붙여 넣을 것 |
| --- | --- |
| 2단계 | 설계 시트, 근거 카드 |
| 3단계 | 위 + 고른 제목과 구성 |
| 4~6단계 | 위 + 현재 초안 (편집 전 복사본은 필자가 따로 보관) |

단계 번호는 몰라도 된다. 붙여 넣은 자료에서 시작할 단계를 판단한다. 필수 항목이 빠졌을 때만 해당 항목을 묻고, 실제 수행하지 않은 앞 단계는 완료로 표시하지 않는다.

## 제출 전 안전 수칙

1. 다른 사람의 이름, 사정, 연락처, 대화 내용은 본인 동의 없이 쓰지 않는다. 필요하면 "조원 한 명"처럼 바꾼다.
2. 필자 자신의 건강, 가족, 금전 같은 사적 정보는 글에 꼭 필요한 만큼만 쓰도록 먼저 알린다.
3. 과제로 제출할 때는 교과와 학교의 AI 활용 규정을 필자가 확인한다. 스킬은 6단계에서 AI 활용 표시 문장만 제안하고, 규정을 대신 판단하지 않는다.
4. 수업 채팅이나 공개 게시판에는 칼럼 전문 대신 주장 한 문장이나 기준 한 줄만 공유하도록 안내한다.
5. 출처가 있는 자료를 쓰면 필자가 출처를 직접 확인해 적는다. 스킬은 출처를 만들지 않는다.
