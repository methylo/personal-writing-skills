# 내 글 정본 (정본 스킬)

이 문서는 필자가 어떻게 말하는지를 정한다. 사실·근거·구성 규칙은 메인 스킬이 맡는다. 일괄 치환 목록이 아니다. 문장의 의미를 확인하며 적용한다.

## 1. 문체

1. '다'체로 쓴다.
2. 주어는 '나'로 쓰고, '필자'나 '우리'로 바꾸지 않는다.
3. 한 문장에는 생각 하나만 담고, 두 줄을 넘기지 않는다.
4. 거창한 말과 가르치는 말투('~해야 한다'의 반복)를 피한다.

## 2. AI 흔적 지우기

원칙: AI 탐지를 피하려는 편집이 아니다. 누구 글에나 들어가는 상투·과장·반복을 줄여 내 문장을 남기는 편집이다. AI 활용 표시는 메인 스킬이 맡는다.

1. 일반론 시작: '현대사회에서', '요즘 많은 사람들이'로 여는 문장
2. 상투 표현: '소중한 깨달음', '바쁜 일상 속'처럼 누구 글에나 들어가는 말
3. 과장된 결론: '삶을 바꾸는', '완전히 달라졌다'처럼 경험보다 큰 말
4. 효과 단정: 메모에 없는 결과를 '~하자 향상됐다'처럼 단정하는 문장
5. 같은 뜻 반복: 같은 생각을 다른 문장으로 되풀이하는 곳
6. 기계적 나열: 늘 셋씩 묶거나 '첫째·둘째·셋째'를 습관처럼 쓰는 곳
7. 흐리는 말끝: '~할 수 있다', '~라고 할 수 있다'의 반복

## 3. 표현·표기 사전

가. 헷갈리는 말 (국어 표기 기준)

| 헷갈리는 말 | 바른 쓰임 |
| --- | --- |
| 되 / 돼 | '되어'로 바꿔 말이 되면 '돼' (안 돼, 돼서) |
| 안 / 않 | 짧은 부정은 '안', '-지 않다'는 '않' |
| 로서 / 로써 | 자격은 '로서', 수단은 '로써' |
| 금새 → 금세 | '금시에'가 줄어든 말이라 '금세' |
| 몇일 → 며칠 | 언제나 '며칠' |
| 맞추다 / 맞히다 | 정답을 맞히다, 퍼즐을 맞추다 |
| 왠지 / 웬 | '왜인지'는 '왠지', 그 밖에는 '웬' (웬일) |
| -든지 / -던지 | 고르는 것은 '-든지', 지난 일은 '-던지' |

나. 확인 원칙: 목록에 없는 말의 표기나 뜻이 확실하지 않으면 고치지 않고 `확인 필요: 표준국어대사전`으로 표시한다. 사전 뜻풀이를 지어내지 않는다.

다. 내가 쓰는 말 ↔ 피할 말 (필자가 채운다)

- 용어 통일: 같은 대상은 처음 부른 말로 끝까지 부른다.
- 예시) '너무', '정말' → 빼거나 사실로 바꾼다
- 예시) '~것 같다' → 한 글에 한 번까지
- (내 말을 한 줄씩 더한다)

## 4. 자기 표현 방식 (필자가 채운다)

괄호 안은 예시다. 필자가 채운 줄만 적용하고, 빈 줄과 예시는 적용하지 않는다.

- 생각을 드러내는 방식: (예: 장면을 먼저 쓰고, 생각은 한 문장으로 붙인다)
- 주장의 강도: (예: 내 경험 범위에서만 말하고, 남에게는 질문으로 건넨다)
- 마무리 습관: (예: 독자에게 건네는 한 문장으로 끝낸다)
- 내 문장 견본: (내가 쓴 문장 1~2개를 그대로 붙인다. 말투를 맞출 때 기준이 된다)

## 5. 적용 방법

- 기준에 어긋난 문장은 최소한으로 고친다. 필자의 사실과 관점은 바꾸지 않는다.
- 필자에게 낯선 문체를 덧씌우지 않는다. 내 문장 견본이 있으면 그 말투에 맞춘다.
- 「나만의 글쓰기」와 함께 쓸 때 정본을 읽는 때와 설명 방식은 메인 스킬의 「정본 확인·적용·설명」을 따른다. 이 정본만 단독으로 쓸 때는 고친 문장마다 해당 항목 번호(예: 2-5)를 밝힌다.
- 4번과 6번에 필자가 쓴 기준을 실제로 적용했다면 해당 설명에 함께 밝힌다. 빈칸·괄호 속 예시는 필자의 취향으로 적용하지 않는다.
- 기준이 부딪치면 6 내 기준 칸 → 4 자기 표현 방식 → 1~3 기본 기준 순서로 따른다.

## 6. 내 기준 칸

강의나 글쓰기가 끝날 때 기준 후보를 제안할 수 있다. 필자가 정본 변경·저장을 요청했을 때만 한 줄씩 반영한다. 원고 수정 승인만으로 이 칸을 자동으로 바꾸지 않는다.

- (여기에 내 기준을 한 줄씩 더한다)
